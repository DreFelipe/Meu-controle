# Controle Financeiro Pessoal (Meu Controle)

Projeto acadêmico desenvolvido para a disciplina de **Gestão da Qualidade de Software (IBMR)**.

## 🌐 Acesso à Aplicação
O sistema encontra-se publicado e funcional no link:
👉 [https://meucontrolefinan.netlify.app/](https://meucontrolefinan.netlify.app/)

## 🚀 Como executar localmente
1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` diretamente em qualquer navegador web moderno (Chrome, Edge, Firefox) ou utilize uma extensão como o *Live Server* no VS Code.

## 🛠️ Tecnologias Utilizadas
* HTML5, CSS3 e JavaScript
* Persistência de dados local (`LocalStorage`)
